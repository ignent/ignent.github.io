家装五大施工阶段与材料分类

ZIP2025/1/11...大约 8 分钟家装装修流程施工阶段

本文档严格区分家装各施工步骤的主材与辅材，明确每种材料的核心要求、国标标准、规格参数及使用要点，适配视频弹窗展示、截图核对、现场验收等多种场景，参数无遗漏、分类无混淆，方便施工前核对材料、施工中把控质量、施工后验收复盘。

第一步 墙体新建补烂

一、主材（核心构成墙体，决定基础质量）

主材名称核心要求（国标 + 规格 + 采购 / 施工要点）
红砖 / 轻质砖优先轻质砖为主、红砖为辅；全红砖仅能砌筑在有梁位置；采购需按 5% 损耗核算用量
水泥选用 PO42.5 普通硅酸盐水泥；必须符合 GB 175-2023《通用硅酸盐水泥》标准；保质期需≥3 个月，外观无结块、无受潮变质
砂子规格选中沙，含泥量≤3%；优先选用河沙，严禁使用水洗海沙（易返碱、影响强度）
钢筋规格 Φ6mm 或 Φ8mm；品类为 HRB400 级螺纹钢，符合 GB 1499.2-2024《钢筋混凝土用钢 第 2 部分：热轧带肋钢筋》；用途仅限新老墙体衔接、门洞过梁加固
植筋胶符合 GB/T 37127-2018《混凝土结构工程用锚固胶》；品类选改性环氧类或改性乙烯基酯类锚固胶；A 级、B 级均满足施工需求，用于钢筋固定锚固

二、辅材（辅助施工，提升稳定性、功能性，防后期隐患）

辅材名称核心要求（规格 + 用途）
钢丝网孔径 10-15mm，丝径≥0.8mm；专用新旧墙体衔接处，防止后期墙面开裂
隔音棉厚度≥2cm，选铝箔款；提升墙体隔音效果，适配对隔音有需求的空间
阻尼垫厚度≥3mm，选薄铝膜款；辅助隔音、减少震动传递，搭配隔音棉使用

第二步 水电改造（家装心脏工程，主材决定使用安全）

一、主材（核心功能材料，承载水电传输，关乎安全耐用）

主材名称核心要求（国标 + 规格 + 选型 / 使用要点）
电线品类可选 BV 型（硬线）、BVR 型（软线）；规格 1.5-6 平方（按不同区域用电需求匹配）；基础款符合 GB/T 5023-2008；阻燃 / 耐火 / 低烟无卤等特殊款，需符合 GB/T 19666-2019 对应标准
PPR 水管及管件基础款符合 GB/T 18742；增强款参考 CJ/T 258-2014；抗压等级选 S3.2 或 S2.5（等级越小，壁厚越厚，耐用性越强）；全屋水路核心载体
空开符合 GB 10963.1-2020；触点选银合金材质，外壳阻燃等级 V0 级；优先选大牌，承载电路过载保护核心功能
漏保符合 GB 16917.1-2014；动作电流≤30mA，动作时间≤0.1 秒；带试验按钮，每月需测试 1 次；防漏电触电，核心安全主材
排水管固定 PVC-U 材质，双标达标：管材符合 GB/T 5836.1，管件符合 GB/T 5836.2；马桶排污管 Φ110mm、壁厚≥3.2mm；地漏 / 面盆 / 阳台管 Φ50mm、壁厚≥2.0mm；厨房水槽（接洗碗机）Φ75mm、壁厚≥2.3mm；承载污水排放核心功能

二、辅材（辅助安装、防护，保障施工规范，延长主材寿命）

辅材名称核心要求（国标 + 规格 + 使用要点）
PVC 穿线管及配件壁厚≥1.6mm，直径 16mm/20mm 按需选择；阻燃等级 B1 级；双标符合 JG/T 3050-1998+GB/T 20284-2017；穿线面积≤管内总面积 40%；保护电线，方便后期检修
管卡（水电走天用）可选金属款或塑料款，按需匹配水管规格；固定水管，防止水管移位、晃动
保温棉（水电走天用）厚度≥15mm；包裹水管，防止冬季冻裂、夏季冷凝水渗水，保护水管同时避免墙面受潮

第三步 防水施工（厨卫兜底工程，主材决定防水效果）

一、主材（核心防水载体，直接决定是否渗漏）

主材名称适用部位核心要求（国标 + 选型要点）
聚合物防水浆料（刚性）墙面符合 JC/T2090-2011；刚性防水附着力强，贴砖不易脱落，适配墙面防水
聚合物水泥防水砂浆（刚性）墙面符合 JC/984；刚性属性，贴合墙面基层，保障贴砖牢固度，墙面防水核心材料
聚合物水泥防水涂料（柔性）地面符合 GB23445-2009；选 Ⅱ 型或 Ⅲ 型；柔性可适配地面轻微变形，防止开裂漏水，地面防水核心材料

二、辅材（辅助加固，封堵细节隐患，提升防水完整性）

辅材名称适用场景核心要求（国标 + 用途）
速凝型堵漏王墙角、管根、缝隙符合 GB23440-2009；速凝固化，快速封堵墙角、管根等易渗漏死角，杜绝细节渗漏
纺织布管道切割后周边搭配防水涂膜使用；做胎体加固，增强管道周边防水涂层的韧性和密封性，防止管道周边开裂渗漏
防水涂膜（配套纺织布）管道切割后周边搭配纺织布，提升胎体加固效果，封堵管道切割后缝隙，辅助主材强化防水

第四步 木工瓦工（面子工程里子活，主材决定颜值 + 耐用性）

一、木工板块

（一）主材（核心构成木作基层 / 饰面，决定稳固性 + 环保性）

主材名称核心要求（国标 + 规格 + 选型 / 施工要点）
轻钢龙骨吊顶核心骨架，符合 GB/T 11981-2024；家装常用 U 形、C 形、V 形；U 形主龙骨：38 型厚≥1mm，50/60 型厚≥1.2mm；C 形主龙骨：同 U 形规格标准，副龙骨 50 型厚≥0.5mm、60 型厚≥0.6mm；V 形主龙骨厚≥0.8mm，造型龙骨厚≥1mm，副龙骨厚≥0.5mm；决定吊顶稳固性，杜绝后期下沉
石膏板吊顶 / 墙面基层，环保需符合 GB/T 39600-2021《人造板及其制品甲醛释放量分级》E0 级及以上（需出具检测报告并验证真伪）；普通区域用普通纸面石膏板，厨卫 / 阳台潮湿区域用耐水石膏板（耐水石膏板吸水率≤10%）；厚度≥9.5mm，防止后期变形、开裂
欧松板木作基层（如柜体、造型），环保需符合 GB/T 39600-2021 E0 级及以上（需出具检测报告并验证真伪）；无额外特殊选型要求，核心盯紧环保性，避免甲醛超标

（二）辅材

无额外新增辅材，水泥、砂子要求同 “墙体新建补烂” 步骤，此处不重复赘述，统一按前期标准核对即可。

二、瓦工板块

（一）主材（核心粘贴材料，决定瓷砖铺贴牢固度，防后期掉砖）

主材名称核心要求（国标 + 选型关键，防踩坑）
瓷砖胶真瓷砖胶需符合 JC/T547-2017（必核标准！）；严禁用 GB/T25181-2019 预拌砂浆替代（仅为普通砂浆，无瓷砖粘贴附着力）；不同砖型、规格匹配对应等级，参考 JC/T 60006-2020；瓦工核心主材，直接决定瓷砖是否空鼓、掉砖

（二）辅材（水泥 / 砂子）

辅材名称核心要求（同前期施工标准，统一核对）
水泥 / 砂子水泥选 PO42.5 普通硅酸盐水泥（GB 175-2023）；砂子选中沙（含泥量≤3%、优先河沙）；辅助瓷砖胶施工，部分场景可用于基层找平

第五步 油工墙面（最终表面功夫，主材决定颜值 + 环保）

一、主材（核心构成墙面饰面，决定平整度、颜值、环保性）

主材名称分类/用途核心要求（国标+选型要点）
石膏嵌缝石膏用于水电开槽修补、石膏板接缝填充；符合JC/T2075-2011
找平石膏用于大面积墙面基层找平；符合GB/T28627-2023重质抹灰石膏
室内腻子一般型符合JG/T 298-2010；适配客厅、卧室等干燥区域
耐水型符合JG/T 298-2010；适配厨卫周边、阳台等潮湿区域
柔韧型符合JG/T 298-2010；适配墙面易开裂区域
乳胶漆底漆封固基层、抗碱、提升附着力；符合GB 18582-2020
面漆选GB/T9756-2018一等品及以上；儿童房可选GB/T34676-2017儿童漆

二、辅材（辅助提升附着力，保障施工效果，防后期脱落、起壳）

辅材名称适用场景核心要求（国标）
界面剂混凝土墙面/瓷砖拉毛符合JC/T 907-2018
新建墙体抹灰前符合JG/T 468-2015
铲除大白后墙面/自流平施工前符合JC/T 2329-2015

补充说明

  1. 所有材料国标标准为必核项，进场验收时需核对产品检测报告，确保符合对应国标要求，杜绝不合格材料进场；
  2. 主材与辅材区分核心：主材为各施工步骤的核心功能载体，直接决定施工质量和使用效果；辅材为辅助主材施工、弥补细节隐患、提升功能性的材料，不可替代主材使用；
  3. 重复出现的辅材（如水泥、砂子），统一按 “墙体新建补烂” 步骤的要求执行，无需重复采购和核对标准。
