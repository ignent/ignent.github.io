ADB

ZIP2026/7/3...大约 1 分钟

一、下载安装 ADB & Fastboot

  1. 下载官方 SDK Platform Tools（包含 adb 和 fastboot）：
    • 官网：https://developer.android.com/studio/releases/platform-tools
  2. 下载 Windows 压缩包 .zip → 解压到目录，例如：
C:\Android\platform-tools

二、环境变量 & 关键配置

  1. 将解压目录加入 系统 Path：
C:\Android\platform-tools
  1. 关键点：
    • 解压目录下必须包含 adb.exe 和 fastboot.exe
    • 使用 USB 调试连接手机时，需在手机 设置 → 开发者选项 → USB 调试 打开
    • 如果连接 Android 设备失败，可能需要安装对应厂商 USB 驱动（如 Google USB Driver / 小米 / 华为驱动）

三、验证安装

打开 CMD / PowerShell：

adb version
fastboot --version
  • 正常输出示例：
Android Debug Bridge version 1.0.41
Fastboot version 30.0.0

连接设备测试：

adb devices
  • 输出列表中显示设备序列号表示成功连接

四、快速测试命令

  • 查看设备状态：
adb get-state
fastboot devices
  • 进入 shell：
adb shell
  • 重启到 fastboot：
adb reboot bootloader
  • 常用 Fastboot 刷机命令：
fastboot flash recovery recovery.img
fastboot reboot

注意

  • 权限问题：在 Windows 10/11，连接设备时可能弹出 “是否允许 USB 调试”，必须确认。
  • 多个设备：用 adb -s <device_serial> ... 指定操作目标。
  • 卸载驱动 / 冲突：遇到设备无法识别，可以在设备管理器卸载旧驱动，再重新安装驱动 (Google-USB-Driver)。
