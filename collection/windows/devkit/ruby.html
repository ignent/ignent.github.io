Ruby

ZIP2026/8/24...小于 1 分钟

一、下载安装 Ruby

  • 官网：https https://www.ruby-lang.org/en/downloads/
  • Windows 推荐下载 Ruby+Devkit 安装包（带开发工具）
  • 双击安装，选择默认路径，例如：
C:\Ruby31-x64
  • 勾选 Add Ruby executables to your PATH
  • 安装时选择 MSYS2 Devkit 并完成推荐步骤

二、环境变量

  1. Path 配置 安装程序一般会自动添加：

    C:\Ruby31-x64\bin
C:\Ruby31-x64\msys64\usr\bin

  2. 关键配置

    • DevKit 会自动配置编译工具，可支持安装原生 gem
    • 确保 gem 目录可写（通常在 %USERPROFILE%\Ruby31-x64\lib\ruby\gems\3.1.0 ）

三、验证 Ruby 与 Gem

打开 CMD / PowerShell：

ruby -v
gem -v

四、验证结果

正常输出示例：

ruby 4.0.xp
4.x.x
