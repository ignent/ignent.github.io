Java

ZIP2026/6/23...小于 1 分钟

一、下载安装 JDK

  • 官网：https://www.oracle.com/java/technologies/downloads/

    • 或：OpenJDK（Temurin）
      https://adoptium.net/

  • 下载 Windows x64 Installer (.msi)

  • 双击安装，一路 Next

  • 安装路径示例：

    C:\Program Files\Java\jdk-17

二、环境变量配置

新建 JAVA_HOME

  • 变量名： JAVA_HOME

  • 变量值：

    C:\Program Files\Java\jdk-17

配置 Path

在 Path 中新增：

%JAVA_HOME%\bin

三、验证 javac /java 命令

打开 CMD / PowerShell：

java -version
javac -version

四、验证结果

正常输出示例：

java version "17.0.x"
javac 17.0.x
