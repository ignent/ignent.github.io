NVM(Node)

ZIP2026/6/17...小于 1 分钟

一、下载安装 NVM for Windows

  • GitHub：https://github.com/coreybutler/nvm-windows/releases

  • 下载： nvm-setup.exe

  • 双击安装，一路 Next

  • 默认安装路径即可：

    C:\Program Files\nvm

二、环境变量确认

安装完成后通常已自动配置：

  • NVM_HOME

  • NVM_SYMLINK

    C:\Program Files\nodejs

  • Path 中包含：

    %NVM_HOME%
%NVM_SYMLINK%

三、安装并使用 Node.js

打开 CMD / PowerShell（建议管理员）：

nvm version
nvm install latest
nvm use latest

四、验证安装

node -v
npm -v

输出示例：

v24.x.x
11.x.x

五、配置

nvm 配置 settings.txt

root: \path\to\nvm
path: \path\to\nvm\nodejs
node_mirror: https://npmmirror.com/mirrors/node/

npm 设置模块和缓存

npm config set prefix "\path\to\node_global"
npm config set cache "\path\to\node_cache"

安装 pnpm

npm -g install pnpm

指定 pnpm 存储路径

pnpm config set store-dir /path/to/.pnpm-store
