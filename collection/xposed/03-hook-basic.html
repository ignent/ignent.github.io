Hook基础

ZIP2026/6/12...大约 8 分钟XposedLSPosedHook

概述

本文基于 HookDemo.java 的实际代码，演示 Xposed Hook 的核心技术：实例方法拦截、静态方法拦截、构造函数拦截、字段读写、调用栈追踪。这些技术是逆向分析和应用修改的基础。

测试环境

示例代码针对 com.example.challenge 应用的练习题进行 Hook：

  • 目标类： com.example.challenge.fragment.exercise.Ex012Fragment
  • 目标内部类： Ex012Fragment$CustomObject
  • 调用栈示例类： Ex013Fragment

核心技术实现

1. Hook 实例方法

文件路径： app/src/main/java/com/xposed/hook/HookDemo.java

1.1 基础用法

XposedHelpers.findAndHookMethod(
    "com.example.challenge.fragment.exercise.Ex012Fragment",
    classLoader,
    "instanceMethod",
    String.class,
    new XC_MethodHook() {
        @Override
        protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
            Log.d(TAG, "beforeHookedMethod: " + param.args[0]);
            super.beforeHookedMethod(param);
        }

        @Override
        protected void afterHookedMethod(MethodHookParam param) throws Throwable {
            super.afterHookedMethod(param);
            Log.d(TAG, "afterHookedMethod: " + param.getResult());
        }
    }
);

1.2 参数说明

findAndHookMethod() 参数顺序：

  1. String className - 目标类的完整路径
  2. ClassLoader classLoader - 目标应用的类加载器（从 lpparam.classLoader 获取）
  3. String methodName - 方法名
  4. Object... parameterTypesAndCallback - 参数类型 + Hook 回调

参数类型如何匹配：

// 目标方法签名
public String instanceMethod(String input) { ... }

// Hook 时参数类型声明
"instanceMethod",
String.class,  // 对应 String input
new XC_MethodHook() { ... }

1.3 回调时机

beforeHookedMethod：

  • 在原始方法执行之前调用
  • 可以读取 param.args[] 获取传入参数
  • 可以调用 param.setResult() 跳过原始方法执行
  • 可以修改 param.args[] 改变传入参数

afterHookedMethod：

  • 在原始方法执行之后调用
  • 可以通过 param.getResult() 获取返回值
  • 可以调用 param.setResult() 修改返回值
  • 可以读取 param.args[] （但修改无效）

1.4 实际效果

假设目标方法实现为：

public String instanceMethod(String input) {
    return "result_" + input;
}

当应用调用 instanceMethod("test") 时，Logcat 会输出：

0X->: beforeHookedMethod: test
0X->: afterHookedMethod: result_test

2.1 与实例方法的区别

API 使用完全相同：

  • findAndHookMethod() 的参数结构一致
  • Hook 回调的使用方式一致

区别仅在目标方法的定义：

// 静态方法
public static int staticMethod(int value) { ... }

// 实例方法
public String instanceMethod(String input) { ... }

param.thisObject 的差异：

  • 实例方法： param.thisObject 是调用该方法的对象实例
  • 静态方法： param.thisObject 为 null

3.1 内部类的处理

Java 内部类命名规则：

// Java 源码
public class Ex012Fragment {
    public static class CustomObject {
        public CustomObject(String name) { ... }
    }
}

// 编译后的类名
com.example.challenge.fragment.exercise.Ex012Fragment$CustomObject

内部类在编译后会使用 $ 连接外部类和内部类名。

3.2 构造函数 Hook 时机

CustomObject obj = new CustomObject("test");

执行顺序：

  1. beforeHookedMethod 被调用
  2. 对象分配内存
  3. 执行原始构造函数
  4. afterHookedMethod 被调用
  5. new 表达式返回对象引用

特殊用法：在 afterHookedMethod 中可以通过 param.thisObject 获取刚构造完成的对象实例。

4. 字段读写

XposedHelpers.findAndHookMethod(
    "com.example.challenge.fragment.exercise.Ex012Fragment",
    classLoader,
    "addCounter",
    new XC_MethodHook() {
        @Override
        protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
            int counter = XposedHelpers.getIntField(param.thisObject, "counter");
            Log.d(TAG, "beforeHookedMethod: " + counter);
            XposedHelpers.setIntField(param.thisObject, "counter", 0);
            super.beforeHookedMethod(param);
        }

        @Override
        protected void afterHookedMethod(MethodHookParam param) throws Throwable {
            super.afterHookedMethod(param);
            int counter = XposedHelpers.getIntField(param.thisObject, "counter");
            Log.d(TAG, "afterHookedMethod: " + counter);
        }
    }
);

4.1 读取字段： getXxxField()

// 读取 int 类型字段
int value = XposedHelpers.getIntField(param.thisObject, "counter");

// 读取 Object 类型字段
String name = (String) XposedHelpers.getObjectField(param.thisObject, "name");

// 读取静态字段
int staticValue = XposedHelpers.getStaticIntField(targetClass, "staticCounter");

4.3 效果

假设目标类实现为：

public class Ex012Fragment {
    private int counter = 10;
    
    public void addCounter() {
        counter++;  // counter 变为 11
    }
}

Hook 后的执行流程：

1. beforeHookedMethod 执行
   - 读取 counter，打印 "10"
   - 强制设置 counter = 0

2. 原始 addCounter() 执行
   - counter++ → counter 变为 1

3. afterHookedMethod 执行
   - 读取 counter，打印 "1"

Logcat 输出：

0X->: beforeHookedMethod: 10
0X->: afterHookedMethod: 1

5. 调用栈追踪

XposedHelpers.findAndHookMethod(
    "com.example.challenge.fragment.exercise.Ex013Fragment",
    classLoader,
    "getStackTrace",
    new XC_MethodHook() {
        @Override
        protected void afterHookedMethod(MethodHookParam param) throws Throwable {
            super.afterHookedMethod(param);
            StackTraceElement[] elements = Thread.currentThread().getStackTrace();
            for (StackTraceElement element : elements) {
                String className = element.getClassName();
                String methodName = element.getMethodName();
                Log.d(TAG, "调用者类名: " + className + ", 方法名: " + methodName);
            }
        }
    }
);

5.1 调用栈的作用

逆向分析中的应用：

  1. 追踪方法调用链：确定某个加密方法是被哪个模块调用的
  2. 定位关键逻辑：找到触发风控检测的上层调用
  3. 绕过检测：识别不希望暴露的调用路径

5.2 调用栈结构

StackTraceElement[] elements = Thread.currentThread().getStackTrace();

每个 StackTraceElement 包含：

String className = element.getClassName();        // 类名
String methodName = element.getMethodName();      // 方法名
String fileName = element.getFileName();          // 源文件名
int lineNumber = element.getLineNumber();         // 行号

5.3 实际输出示例

假设调用链为：

Activity.onCreate()
  → FragmentManager.showFragment()
    → Ex013Fragment.onViewCreated()
      → Ex013Fragment.getStackTrace()

Logcat 输出：

0X->: 调用者类名: dalvik.system.VMStack, 方法名: getThreadStackTrace
0X->: 调用者类名: java.lang.Thread, 方法名: getStackTrace

核心 Hook 类

文件： app/src/main/java/com/xposed/hook/HookDemo.java

package com.xposed.hook;

import android.util.Log;

import de.robv.android.xposed.XC_MethodHook;
import de.robv.android.xposed.XposedHelpers;
import de.robv.android.xposed.callbacks.XC_LoadPackage;

public class HookDemo {
    private static final String TAG = "0X->";

    public static void hook(XC_LoadPackage.LoadPackageParam lpparam) {
        ClassLoader classLoader = lpparam.classLoader;
        
        // 1. Hook 实例方法
        hookInstanceMethod(classLoader);
        
        // 2. Hook 静态方法
        hookStaticMethod(classLoader);
        
        // 3. Hook 构造函数
        hookConstructor(classLoader);
        
        // 4. Hook 字段读写
        hookFieldAccess(classLoader);
        
        // 5. Hook 调用栈追踪
        hookStackTrace(classLoader);
    }

    private static void hookInstanceMethod(ClassLoader classLoader) {
        XposedHelpers.findAndHookMethod(
            "com.example.challenge.fragment.exercise.Ex012Fragment",
            classLoader,
            "instanceMethod",
            String.class,
            new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[实例方法] 参数: " + param.args[0]);
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[实例方法] 返回值: " + param.getResult());
                }
            }
        );
    }

    private static void hookStaticMethod(ClassLoader classLoader) {
        XposedHelpers.findAndHookMethod(
            "com.example.challenge.fragment.exercise.Ex012Fragment",
            classLoader,
            "staticMethod",
            int.class,
            new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[静态方法] 参数: " + param.args[0]);
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[静态方法] 返回值: " + param.getResult());
                }
            }
        );
    }

    private static void hookConstructor(ClassLoader classLoader) {
        XposedHelpers.findAndHookConstructor(
            "com.example.challenge.fragment.exercise.Ex012Fragment$CustomObject",
            classLoader,
            String.class,
            new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[构造函数] 参数: " + param.args[0]);
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    Log.d(TAG, "[构造函数] 对象已创建: " + param.thisObject);
                }
            }
        );
    }

    private static void hookFieldAccess(ClassLoader classLoader) {
        XposedHelpers.findAndHookMethod(
            "com.example.challenge.fragment.exercise.Ex012Fragment",
            classLoader,
            "addCounter",
            new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    int counter = XposedHelpers.getIntField(param.thisObject, "counter");
                    Log.d(TAG, "[字段读取] 修改前 counter = " + counter);
                    XposedHelpers.setIntField(param.thisObject, "counter", 0);
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    int counter = XposedHelpers.getIntField(param.thisObject, "counter");
                    Log.d(TAG, "[字段修改] 修改后 counter = " + counter);
                }
            }
        );
    }

    private static void hookStackTrace(ClassLoader classLoader) {
        XposedHelpers.findAndHookMethod(
            "com.example.challenge.fragment.exercise.Ex013Fragment",
            classLoader,
            "getStackTrace",
            new XC_MethodHook() {
                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    StackTraceElement[] elements = Thread.currentThread().getStackTrace();
                    Log.d(TAG, "[调用栈] 共 " + elements.length + " 帧:");
                    for (StackTraceElement element : elements) {
                        Log.d(TAG, "  → " + element.getClassName() + "." + element.getMethodName());
                    }
                }
            }
        );
    }
}

高级技巧

1. 修改返回值

@Override
protected void afterHookedMethod(MethodHookParam param) throws Throwable {
    // 强制修改返回值
    param.setResult("hacked_result");
}

2. 跳过原始方法执行

@Override
protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
    // 直接返回结果，不执行原始方法
    param.setResult("bypass_result");
}

3. 修改传入参数

@Override
protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
    // 修改第一个参数
    param.args[0] = "modified_input";
}

4. 调用原始方法

@Override
protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
    // 手动调用原始方法
    Object result = XposedBridge.invokeOriginalMethod(param.method, param.thisObject, param.args);
    Log.d(TAG, "原始方法返回: " + result);
}

5. 条件 Hook

@Override
protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
    String input = (String) param.args[0];
    if (input.contains("password")) {
        // 只在特定条件下拦截
        param.setResult("***");
    }
}

注意事项

1. ClassLoader 的重要性

// 错误：使用当前模块的 ClassLoader
Class<?> clazz = Class.forName("com.target.app.SomeClass");

// 正确：使用目标应用的 ClassLoader
Class<?> clazz = XposedHelpers.findClass("com.target.app.SomeClass", lpparam.classLoader);

2. 字段访问权限

XposedHelpers 会自动处理 private / protected 字段的访问，无需手动反射。

3. 异常处理

@Override
protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
    try {
        // Hook 逻辑
    } catch (Exception e) {
        Log.e(TAG, "Hook 失败", e);
        // 不要抛出异常，否则会导致应用崩溃
    }
}

4. 性能考虑

Hook 会在每次方法调用时执行，避免在高频方法中进行耗时操作：

// 不推荐：在高频方法中进行 IO 操作
@Override
protected void afterHookedMethod(MethodHookParam param) throws Throwable {
    FileWriter writer = new FileWriter("/sdcard/log.txt", true);  // 每次都打开文件
    writer.write(param.getResult().toString());
    writer.close();
}

// 推荐：使用异步队列
@Override
protected void afterHookedMethod(MethodHookParam param) throws Throwable {
    logQueue.offer(param.getResult().toString());  // 交给后台线程处理
}

对比传统反射

特性Xposed Hook传统 Java 反射
访问 private 方法直接调用需要 setAccessible(true)
拦截所有调用自动拦截无法拦截
修改返回值支持不支持
性能开销较低较高
代码侵入性无侵入需要修改调用代码

总结

本文介绍的 5 种 Hook 技术是 Xposed 开发的核心：

  1. 实例方法 Hook：拦截对象方法调用
  2. 静态方法 Hook：拦截类方法调用
  3. 构造函数 Hook：拦截对象创建
  4. 字段读写：直接修改对象状态
  5. 调用栈追踪：分析方法调用链

掌握这些技术后，可以进一步学习：

  • 加密链路 Hook：拦截加密算法
  • 反检测技术：隐藏 Hook 痕迹
  • 跨进程数据传递：模块间通信
