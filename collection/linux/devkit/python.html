Python 部署

ZIP2026/6/17...大约 4 分钟

提示

下面默认以 Debian 系服务器为例，示例项目名统一写成 demo 。如果用的是 Django、Flask、FastAPI，只需要替换启动命令即可。

一、适用场景

这篇文档适合这些场景：

  • Django / Flask / FastAPI 的生产部署
  • 使用 venv 管理依赖
  • 使用 Gunicorn 或 Uvicorn 对外提供服务
  • 需要 Nginx 、 systemd 、回滚和日志排查

二、机器初始化

先把系统和基础工具装好：

sudo apt update
sudo apt full-upgrade -y
sudo apt autoremove -y
sudo apt install -y \
  curl wget git vim unzip zip tar rsync tmux htop lsof jq \
  ca-certificates gnupg nginx ufw

再创建服务账号和目录：

sudo adduser --system --group --home /opt/apps/demo svc-demo
sudo mkdir -p /opt/apps/demo/releases /opt/apps/demo/shared /data/logs/demo
sudo chown -R svc-demo:svc-demo /opt/apps/demo /data/logs/demo

三、环境安装

Python 服务端最常用的是这一组：

sudo apt install -y \
  python3 python3-venv python3-pip python3-dev \
  build-essential pkg-config
python3 --version
pip3 --version

如果项目要连 PostgreSQL 或 MySQL，可以把头文件装上：

sudo apt install -y libpq-dev default-libmysqlclient-dev

四、项目目录规划

推荐保留发布目录、共享目录和日志目录：

/opt/apps/demo
├── current -> /opt/apps/demo/releases/2026-05-20-120000
├── releases
│   ├── 2026-05-19-100000
│   └── 2026-05-20-120000
└── shared
    ├── .env
    ├── media
    └── static

/data/logs/demo

这里比较关键的是：

  • 每个版本自己带一套代码
  • 环境变量和上传文件不跟着版本切换
  • current 软链负责当前线上版本

五、部署流程

先准备一个新的发布目录，并把代码复制进去：

sudo mkdir -p /opt/apps/demo/releases/2026-05-20-120000
sudo rsync -av ./ /opt/apps/demo/releases/2026-05-20-120000/
sudo chown -R svc-demo:svc-demo /opt/apps/demo/releases/2026-05-20-120000

然后进入发布目录创建虚拟环境并安装依赖：

cd /opt/apps/demo/releases/2026-05-20-120000
sudo -u svc-demo python3 -m venv .venv
sudo -u svc-demo ./.venv/bin/pip install --upgrade pip
sudo -u svc-demo ./.venv/bin/pip install -r requirements.txt

把环境变量写到共享目录：

sudo tee /opt/apps/demo/shared/.env >/dev/null <<'EOF'
APP_ENV=prod
SECRET_KEY=change-me
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=appdb
DB_USER=appuser
DB_PASS=change-me
EOF
sudo chown svc-demo:svc-demo /opt/apps/demo/shared/.env

如果是 Django，还有：

cd /opt/apps/demo/releases/2026-05-20-120000
sudo -u svc-demo ./.venv/bin/python manage.py migrate
sudo -u svc-demo ./.venv/bin/python manage.py collectstatic --noinput

最后切换软链：

sudo ln -sfn /opt/apps/demo/releases/2026-05-20-120000 /opt/apps/demo/current
sudo chown -h svc-demo:svc-demo /opt/apps/demo/current

六、服务守护与开机自启

Gunicorn 例子，适合 Django 和 Flask：

[Unit]
Description=demo python service
After=network.target

[Service]
Type=simple
User=svc-demo
Group=svc-demo
WorkingDirectory=/opt/apps/demo/current
EnvironmentFile=-/opt/apps/demo/shared/.env
ExecStart=/opt/apps/demo/current/.venv/bin/gunicorn --workers 2 --bind 127.0.0.1:8000 app.wsgi:application
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

写入服务文件：

sudo tee /etc/systemd/system/demo.service >/dev/null <<'EOF'
[Unit]
Description=demo python service
After=network.target

[Service]
Type=simple
User=svc-demo
Group=svc-demo
WorkingDirectory=/opt/apps/demo/current
EnvironmentFile=-/opt/apps/demo/shared/.env
ExecStart=/opt/apps/demo/current/.venv/bin/gunicorn --workers 2 --bind 127.0.0.1:8000 app.wsgi:application
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

如果是 FastAPI，把启动命令改成：

ExecStart=/opt/apps/demo/current/.venv/bin/gunicorn -k uvicorn.workers.UvicornWorker --workers 2 --bind 127.0.0.1:8000 app.main:app

启用并启动：

sudo systemctl daemon-reload
sudo systemctl enable --now demo
sudo systemctl status demo

七、网络访问与对外暴露

Python 服务建议只监听本机 8000 端口，再交给 Nginx ：

server {
    listen 80;
    server_name demo.example.com;

    location /static/ {
        alias /opt/apps/demo/shared/static/;
    }

    location /media/ {
        alias /opt/apps/demo/shared/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

写入配置并启用：

sudo tee /etc/nginx/sites-available/demo >/dev/null <<'EOF'
server {
    listen 80;
    server_name demo.example.com;

    location /static/ {
        alias /opt/apps/demo/shared/static/;
    }

    location /media/ {
        alias /opt/apps/demo/shared/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

sudo ln -sfn /etc/nginx/sites-available/demo /etc/nginx/sites-enabled/demo
sudo nginx -t
sudo systemctl reload nginx

八、日志与监控

最常用的排查命令：

journalctl -u demo -f
sudo systemctl status demo
sudo ss -lntp | grep 8000
curl http://127.0.0.1:8000/

看依赖和 Python 解释器时，常用：

source /opt/apps/demo/current/.venv/bin/activate
python --version
pip freeze | head

Nginx 日志同样要一起看：

sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log

九、备份与回滚

代码回滚还是优先用软链切回旧版本：

sudo ln -sfn /opt/apps/demo/releases/2026-05-19-100000 /opt/apps/demo/current
sudo systemctl restart demo

Python 项目备份：

  • /opt/apps/demo/shared/.env
  • /opt/apps/demo/shared/media
  • 数据库
  • 可能的定时任务配置

配置和媒体文件打包：

sudo tar czf /tmp/demo-python-backup.tar.gz /opt/apps/demo/shared

十、安全加固

  • 不要全局 pip install 直接跑生产项目
  • 服务进程不用 root
  • 只暴露 80 、 443 ，应用端口留在本机
  • .env 不要放进 Git

常用 UFW 放行：

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

十一、常见故障排查

1. ModuleNotFoundError

大多数时候是虚拟环境没装完整，或者服务没指向正确的 .venv ：

source /opt/apps/demo/current/.venv/bin/activate
pip list
sudo systemctl cat demo

2. 502 Bad Gateway

先看 Python 进程，再看 Nginx：

sudo systemctl status demo
journalctl -u demo -n 100
sudo nginx -t

3. 静态文件 / 媒体文件 404

优先看 Nginx alias 路径和目录权限：

ls -lah /opt/apps/demo/shared/static
ls -lah /opt/apps/demo/shared/media

4. 迁移失败

如果是 Django，单独执行迁移看报错：

cd /opt/apps/demo/current
source .venv/bin/activate
python manage.py migrate

5. 端口没起来

sudo ss -lntp | grep 8000

十二、上线检查清单

  • python3 --version 正常
  • 依赖已安装到目标版本目录的 .venv
  • systemctl status demo 为 active (running)
  • nginx -t 通过
  • curl 127.0.0.1:8000 能返回
  • 静态文件、媒体文件可访问
  • 数据库连接、迁移、环境变量都已验证
  • 旧版本目录仍在，可随时回滚
