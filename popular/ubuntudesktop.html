Ubuntu Desktop 26.04 LTS 安装和配置

ZIP2026/7/3...大约 7 分钟UbuntuLinuxDesktop

初始化：

sudo apt update
sudo apt full-upgrade -y
sudo apt autoremove -y

1. 时间同步

当前使用 chrony ，并用 chronyc 查看状态、校准时间。 chronyc 由 chrony 包提供。

sudo apt install -y chrony
sudo systemctl disable --now systemd-timesyncd
sudo systemctl enable --now chrony

配置 Chrony 时间源：

sudo cp /etc/chrony/chrony.conf /etc/chrony/chrony.conf.bak
sudoedit /etc/chrony/chrony.conf

在 /etc/chrony/chrony.conf 中保留或加入：

pool ntp.aliyun.com iburst
pool time1.cloud.tencent.com iburst
pool cn.pool.ntp.org iburst
makestep 1.0 3
rtcsync

重启并用 chronyc 检查：

sudo systemctl restart chrony
chronyc sources -v
chronyc tracking
sudo chronyc makestep

2. Fish、Fisher、Starship

安装 Fish 和 Starship：

sudo apt install -y fish starship

把当前用户默认 Shell 改为 Fish：

sudo chsh -s /usr/bin/fish "$(whoami)"

安装 Fisher：

fish -lc 'curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher'

配置 Starship 在 Fish 中默认启动：

mkdir -p ~/.config/fish
touch ~/.config/fish/config.fish
grep -q 'starship init fish' ~/.config/fish/config.fish || \
  printf '\nstarship init fish | source\n' >> ~/.config/fish/config.fish

如果有备份的 Starship 配置，恢复：

mkdir -p ~/.config
cp 备份目录/.config/starship.toml ~/.config/starship.toml

配置终端默认启动路径：

mkdir -p ~/.config/fish
touch ~/.config/fish/config.fish

编辑 ~/.config/fish/config.fish ，加入下面配置：

if status is-interactive
  set default_dir "$HOME/下载"

  if test -d "$default_dir"
      cd "$default_dir"
  end
end

这样只有终端从家目录启动时才会自动切换路径；如果从文件管理器、IDE 或其他目录打开终端，不会被强制跳走。

3. nvm.fish 安装配置

安装 nvm.fish 和 Node.js：

fish -lc '
  fisher install jorgebucaran/nvm.fish &&
  set -Ux nvm_mirror https://npmmirror.com/mirrors/node &&
  set -Ux nvm_default_version lts &&
  nvm install lts &&
  nvm use lts &&
  npm config set registry https://registry.npmmirror.com
'

安装 pnpm 和 yarn，并配置镜像源：

fish -lc '
  nvm use lts &&
  npm install -g pnpm yarn &&
  set -Ux PNPM_HOME $HOME/.local/share/pnpm &&
  fish_add_path $PNPM_HOME &&
  pnpm config set registry https://registry.npmmirror.com &&
  pnpm config set store-dir ~/.local/share/pnpm/store &&
  yarn config set registry https://registry.npmmirror.com
'

当前记录的 Node 环境：

nvm.fish: 2.2.18
Node.js: LTS（当前记录为 v24.18.0）
npm: 11.16.0
pnpm: 通过 npm 全局安装
yarn: 通过 npm 全局安装
nvm 数据目录: ~/.local/share/nvm
pnpm 数据目录: ~/.local/share/pnpm

5. 字体安装

APT 安装中文字体和 JetBrains Mono：

sudo apt install -y \
  fonts-arphic-ukai fonts-arphic-uming fonts-noto-cjk-extra fonts-jetbrains-mono

手动安装字体时，推荐放到当前用户字体目录：

~/.local/share/fonts/

示例：

mkdir -p ~/.local/share/fonts
cp /path/to/fonts/*.{ttf,otf,ttc,otc} ~/.local/share/fonts/ 2>/dev/null || true
fc-cache -fv
fc-match "JetBrains Mono"

如果要安装给所有用户使用，放到系统字体目录：

/usr/local/share/fonts/

示例：

sudo mkdir -p /usr/local/share/fonts/custom
sudo cp /path/to/fonts/*.{ttf,otf,ttc,otc} /usr/local/share/fonts/custom/ 2>/dev/null || true
sudo fc-cache -fv

常见字体文件后缀：

.ttf
.otf
.ttc
.otc

6.3 微信启动失败

Ubuntu 26.04 对旧版桌面环境进行了深度精简，微信这类基于 Qt 或 Electron 框架的桌面应用，可能因为底层 X11 / XCB 图形组件缺失而出现启动失败、窗口不显示、间歇性报错等问题。

建议先一键补齐高频缺失的图形运行库：

sudo apt update
sudo apt install -y \
  xwayland \
  libx11-xcb1 libxkbcommon-x11-0 \
  libxcb1 libxcb-cursor0 libxcb-glx0 libxcb-icccm4 libxcb-image0 \
  libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 libxcb-shape0 \
  libxcb-shm0 libxcb-sync1 libxcb-xfixes0 libxcb-xinerama0 \
  libatk-bridge2.0-0 libgbm1 libgtk-3-0 libnss3 libasound2t64

如果提示找不到 libasound2t64 ，改装旧包名：

sudo apt install -y libasound2

7. 环境软件安装

7.1 基础工具和开发工具

sudo apt install -y \
  apt-transport-https ca-certificates curl gpg jq wget software-properties-common \
  build-essential clang cmake default-jdk gdb git htop \
  libfuse2t64 lldb neovim openjdk-17-jdk openjdk-21-jdk \
  python3-pip chrony tree
包名作用
apt-transport-https让 APT 支持通过 HTTPS 访问软件源；新版本 Ubuntu 通常已内置，保留安装不影响。
ca-certificates系统根证书，用于 HTTPS、Git、curl、wget 等工具验证证书。
curl命令行 HTTP 客户端，常用于下载安装脚本、调用 API。
gpgGnuPG 工具，用于导入、校验软件源签名和文件签名。
jqJSON 命令行处理工具，适合格式化、过滤 API 返回结果。
wget命令行下载工具，适合直接下载文件、镜像和发布包。
software-properties-common提供 add-apt-repository 等软件源管理工具。
build-essentialC/C++ 基础编译工具集合，包含 gcc 、 g++ 、 make 等。
clangLLVM C/C++/Objective-C 编译器。
cmake跨平台构建配置工具，常用于 C/C++ 项目。
default-jdkUbuntu 默认 Java 开发工具包，提供 java 、 javac 等。
gdbGNU 调试器，用于调试 C/C++ 等原生程序。
git版本控制工具，用于拉取、提交和管理代码仓库。
htop交互式进程和资源监控工具。
libfuse2t64FUSE 2 兼容库，很多 AppImage 或旧应用需要它运行。
lldbLLVM 调试器，常配合 Clang、Swift、C/C++ 使用。
neovim终端编辑器，适合作为 Git、命令行和开发环境默认编辑器。
openjdk-17-jdkOpenJDK 17 开发工具包，适合需要 Java 17 的项目。
openjdk-21-jdkOpenJDK 21 开发工具包，适合较新的 Java LTS 项目。
python3-pipPython 3 包管理器，用于安装 Python 命令行工具和依赖。
chrony时间同步服务。
tree以树状结构查看目录内容。

7.2 系统信息工具

sudo apt install -y fastfetch

7.3 系统参数配置

提高 inotify 文件监听数量，适合 VS Code、前端项目、Node.js 工具链等大量文件监听场景：

sudo mkdir -p /etc/sysctl.d
printf 'fs.inotify.max_user_watches = 524288\n' | sudo tee /etc/sysctl.d/99-inotify.conf
sudo sysctl --system
sysctl fs.inotify.max_user_watches

如果系统已有 /usr/lib/sysctl.d/30-localsearch.conf ，它通常是 localsearch 软件包提供的文件，不建议直接修改，避免后续软件包更新覆盖。本机自定义配置放在 /etc/sysctl.d/ 更合适。

确实要直接修改这个文件时：

sudoedit /usr/lib/sysctl.d/30-localsearch.conf
sudo sysctl -p /usr/lib/sysctl.d/30-localsearch.conf

8. chsrc 换源和 XtraDeb 源

安装 chsrc ：

curl -fsSL https://chsrc.run/posix | sudo bash

查看 Ubuntu 可用源：

chsrc list ubuntu

自动选择 Ubuntu 软件源：

sudo chsrc set ubuntu
sudo apt update

添加 XtraDeb Apps 源，用于安装 ungoogled-chromium ：

sudo apt install -y software-properties-common
sudo add-apt-repository -y ppa:xtradeb/apps
sudo apt update
sudo apt install -y ungoogled-chromium ungoogled-chromium-l10n

当前系统对应的源文件是：

/etc/apt/sources.list.d/xtradeb-ubuntu-apps-resolute.sources

9. 输入法

安装 IBus、Rime 和中文语言包：

sudo apt install -y \
  git bash curl ibus-rime librime-bin \
  language-pack-zh-hans language-pack-gnome-zh-hans

Rime 用户配置目录：

~/.config/ibus/rime/

安装 Plum：

cd ~
git clone --depth 1 https://github.com/rime/plum.git ~/.config/ibus/rime/plum

用 Plum 安装雾凇拼音：

cd ~/.config/ibus/rime/plum
bash rime-install iDvel/rime-ice

如果要明确安装到 iBus-Rime 用户目录：

cd ~/.config/ibus/rime/plum
rime_dir="$HOME/.config/ibus/rime" bash rime-install iDvel/rime-ice

双拼用户额外执行，按实际方案替换 double_pinyin_flypy：

cd ~/.config/ibus/rime/plum
bash rime-install iDvel/rime-ice:others/recipes/config:schema=double_pinyin_flypy

常用方案名：

rime_ice                # 雾凇拼音，全拼
double_pinyin           # 自然码双拼
double_pinyin_flypy     # 小鹤双拼
double_pinyin_mspy      # 微软双拼
double_pinyin_sogou     # 搜狗双拼
double_pinyin_abc       # 智能 ABC 双拼
double_pinyin_jiajia    # 拼音加加双拼
double_pinyin_ziguang   # 紫光双拼

如需万象语法模型，按实际方案替换 rime_ice：

cd ~/.config/ibus/rime/plum
bash rime-install iDvel/rime-ice:others/recipes/grammar:schema=rime_ice

启用 IBus 并切换到 Rime：

im-config -n ibus
ibus restart
ibus engine rime

重新部署：

ibus restart

也可以在桌面输入法菜单中选择 Rime 的 “重新部署”。部署后按 F4 切换输入方案。

更新雾凇拼音：

cd ~/.config/ibus/rime/plum
git pull
bash rime-install iDvel/rime-ice
ibus restart

备份和恢复 Rime 配置：

  • 备份
cp -a ~/.config/ibus/rime 备份目录/rime
  • 恢复
mkdir -p ~/.config/ibus
cp -a 备份目录/rime ~/.config/ibus/
ibus restart

当前建议重点备份：

~/.config/ibus/rime/
~/plum/

10. Git 配置

安装 Git：

sudo apt install -y git

设置用户名和邮箱：

git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

常用全局配置：

git config --global init.defaultBranch main
git config --global core.editor "nvim"
git config --global core.quotepath false
git config --global pull.rebase false
git config --global credential.helper store

查看配置：

git config --global --list

如果已有备份：

cp 备份目录/.gitconfig ~/.gitconfig
