Dex 文件结构详解：从格式到逆向实战

ZIP2026/6/15...大约 15 分钟XposedDex逆向工程文件格式

概述

Dex（Dalvik Executable）是 Android 应用的核心可执行文件格式，包含了应用的所有代码、类、方法、字段和字符串信息。理解 Dex 文件结构对于逆向分析、代码修改、脱壳等操作至关重要。

本文将详细解析 Dex 文件的内部结构，并提供实际的逆向分析案例。

为什么要学习 Dex 文件结构

逆向分析场景：

  1. 手动解析混淆代码：了解类、方法、字段的存储方式
  2. 定位隐藏逻辑：通过偏移地址直接访问目标代码
  3. 修复损坏的 Dex：处理加固、脱壳后的文件
  4. 实现自定义工具：编写 Dex 解析器、修改器
  5. 理解 Hook 原理：DexKit、Xposed 等工具的底层机制

Dex 文件整体结构

Dex 文件采用紧凑的二进制格式，主要包含以下部分：

+------------------+
|   DexHeader      |  文件头（魔数、版本、校验和等）
+------------------+
|   StringIds      |  字符串 ID 列表
+------------------+
|   TypeIds        |  类型 ID 列表
+------------------+
|   ProtoIds       |  方法原型 ID 列表
+------------------+
|   FieldIds       |  字段 ID 列表
+------------------+
|   MethodIds      |  方法 ID 列表
+------------------+
|   ClassDef       |  类定义列表
+------------------+
|   Data           |  数据区（字符串、代码、注解等）
+------------------+
|   LinkData       |  链接数据（可选）
+------------------+

Dex 文件核心组件关系如下：

一、DexHeader（文件头）

DexHeader 是 Dex 文件的起始部分，包含文件的元信息。

1.1 结构定义

struct DexHeader {
    uint8_t  magic[8];          // 魔数 "dex\n039\0"
    uint32_t checksum;          // 文件校验和（除 magic 和 checksum 外的内容）
    uint8_t  signature[20];     // SHA-1 签名
    uint32_t file_size;         // 整个文件大小
    uint32_t header_size;       // DexHeader 大小（固定 0x70）
    uint32_t endian_tag;        // 字节序标记（固定 0x12345678）
    uint32_t link_size;         // 链接段大小（通常为 0）
    uint32_t link_off;          // 链接段偏移
    uint32_t map_off;           // DexMapList 偏移
    uint32_t string_ids_size;   // 字符串 ID 数量
    uint32_t string_ids_off;    // 字符串 ID 列表偏移
    uint32_t type_ids_size;     // 类型 ID 数量
    uint32_t type_ids_off;      // 类型 ID 列表偏移
    uint32_t proto_ids_size;    // 方法原型 ID 数量
    uint32_t proto_ids_off;     // 方法原型 ID 列表偏移
    uint32_t field_ids_size;    // 字段 ID 数量
    uint32_t field_ids_off;     // 字段 ID 列表偏移
    uint32_t method_ids_size;   // 方法 ID 数量
    uint32_t method_ids_off;    // 方法 ID 列表偏移
    uint32_t class_defs_size;   // 类定义数量
    uint32_t class_defs_off;    // 类定义列表偏移
    uint32_t data_size;         // 数据段大小
    uint32_t data_off;          // 数据段偏移
};

1.2 实际案例：解析 Dex 文件头

import java.io.*;
import java.util.Arrays;

public class DexHeaderParser {
    public static void parseDexHeader(String filePath) throws IOException {
        try (RandomAccessFile file = new RandomAccessFile(filePath, "r")) {
            // 1. 读取魔数
            byte[] magic = new byte[8];
            file.read(magic);
            System.out.println("魔数: " + new String(magic));
            
            // 2. 读取校验和
            int checksum = Integer.reverseBytes(file.readInt());
            System.out.printf("校验和: 0x%08X\n", checksum);
            
            // 3. 跳过签名
            file.skipBytes(20);
            
            // 4. 读取文件大小
            int fileSize = Integer.reverseBytes(file.readInt());
            System.out.println("文件大小: " + fileSize + " 字节");
            
            // 5. 读取头部大小
            int headerSize = Integer.reverseBytes(file.readInt());
            System.out.printf("头部大小: 0x%02X\n", headerSize);
            
            // 6. 读取各个区域信息
            file.skipBytes(8); // 跳过 endian_tag, link_size, link_off
            int mapOff = Integer.reverseBytes(file.readInt());
            
            int stringIdsSize = Integer.reverseBytes(file.readInt());
            int stringIdsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("字符串数量: %d, 偏移: 0x%X\n", stringIdsSize, stringIdsOff);
            
            int typeIdsSize = Integer.reverseBytes(file.readInt());
            int typeIdsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("类型数量: %d, 偏移: 0x%X\n", typeIdsSize, typeIdsOff);
            
            int protoIdsSize = Integer.reverseBytes(file.readInt());
            int protoIdsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("方法原型数量: %d, 偏移: 0x%X\n", protoIdsSize, protoIdsOff);
            
            int fieldIdsSize = Integer.reverseBytes(file.readInt());
            int fieldIdsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("字段数量: %d, 偏移: 0x%X\n", fieldIdsSize, fieldIdsOff);
            
            int methodIdsSize = Integer.reverseBytes(file.readInt());
            int methodIdsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("方法数量: %d, 偏移: 0x%X\n", methodIdsSize, methodIdsOff);
            
            int classDefsSize = Integer.reverseBytes(file.readInt());
            int classDefsOff = Integer.reverseBytes(file.readInt());
            System.out.printf("类定义数量: %d, 偏移: 0x%X\n", classDefsSize, classDefsOff);
        }
    }
    
    public static void main(String[] args) throws IOException {
        parseDexHeader("/path/to/classes.dex");
    }
}

二、DexStringId（字符串池）

字符串池存储了 Dex 文件中所有的字符串常量，包括类名、方法名、字段名等。

2.1 结构定义

struct DexStringId {
    uint32_t string_data_off;  // 指向 DexStringData 的偏移
};

struct DexStringData {
    uleb128 utf16_size;        // UTF-16 编码的字符数量
    uint8_t data[];            // MUTF-8 编码的字符串（以 \0 结尾）
};

ULEB128 编码：可变长度的无符号整数编码，节省空间。

2.2 读取字符串实战

public class DexStringReader {
    // 读取 ULEB128 编码的整数
    public static int readULeb128(RandomAccessFile file) throws IOException {
        int result = 0;
        int shift = 0;
        int b;
        
        do {
            b = file.readUnsignedByte();
            result |= (b & 0x7F) << shift;
            shift += 7;
        } while ((b & 0x80) != 0);
        
        return result;
    }
    
    // 读取指定 ID 的字符串
    public static String readString(RandomAccessFile file, int stringId, int stringIdsOff) 
            throws IOException {
        // 1. 定位到 StringId 条目
        file.seek(stringIdsOff + stringId * 4);
        int stringDataOff = Integer.reverseBytes(file.readInt());
        
        // 2. 定位到 StringData
        file.seek(stringDataOff);
        int utf16Size = readULeb128(file);
        
        // 3. 读取 MUTF-8 字符串
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        int b;
        while ((b = file.readUnsignedByte()) != 0) {
            baos.write(b);
        }
        
        return new String(baos.toByteArray(), "UTF-8");
    }
    
    // 读取所有字符串
    public static void dumpAllStrings(String dexPath) throws IOException {
        try (RandomAccessFile file = new RandomAccessFile(dexPath, "r")) {
            // 读取头部信息
            file.seek(0x38); // string_ids_size 的偏移
            int stringIdsSize = Integer.reverseBytes(file.readInt());
            int stringIdsOff = Integer.reverseBytes(file.readInt());
            
            System.out.println("字符串总数: " + stringIdsSize);
            
            // 遍历所有字符串
            for (int i = 0; i < stringIdsSize; i++) {
                String str = readString(file, i, stringIdsOff);
                System.out.printf("[%04d] %s\n", i, str);
            }
        }
    }
}

四、DexProtoId（方法原型）

方法原型定义了方法的返回值类型和参数类型列表，多个方法可以共享同一个原型。

4.1 结构定义

struct DexProtoId {
    uint32_t shorty_idx;        // 简短描述符（字符串索引）
    uint32_t return_type_idx;   // 返回类型（类型索引）
    uint32_t parameters_off;    // 参数列表偏移（指向 DexTypeList）
};

struct DexTypeList {
    uint32_t size;              // 参数数量
    uint16_t list[size];        // 参数类型索引数组
};

shorty 描述符：简化表示，只包含返回值和参数的基本类型标识。

示例：

  • VL → void method(Object)
  • III → int method(int, int)
  • ZLS → boolean method(Object, short)

4.2 解析方法原型

public static String readProto(RandomAccessFile file, int protoId,
                               int protoIdsOff, int typeIdsOff, int stringIdsOff) 
        throws IOException {
    // 1. 定位到 ProtoId
    file.seek(protoIdsOff + protoId * 12);
    int shortyIdx = Integer.reverseBytes(file.readInt());
    int returnTypeIdx = Integer.reverseBytes(file.readInt());
    int parametersOff = Integer.reverseBytes(file.readInt());
    
    // 2. 读取返回类型
    String returnType = readType(file, returnTypeIdx, typeIdsOff, stringIdsOff);
    
    // 3. 读取参数列表
    StringBuilder params = new StringBuilder("(");
    if (parametersOff != 0) {
        file.seek(parametersOff);
        int paramSize = Integer.reverseBytes(file.readInt());
        
        for (int i = 0; i < paramSize; i++) {
            int typeIdx = Short.reverseBytes(file.readShort()) & 0xFFFF;
            String paramType = readType(file, typeIdx, typeIdsOff, stringIdsOff);
            params.append(paramType);
        }
    }
    params.append(")");
    
    return params + returnType;
}

输出示例：

(Ljava/lang/String;I)V         → void method(String, int)
()Ljava/lang/Object;            → Object method()
(II)I                           → int method(int, int)

public static void dumpMethodCode(RandomAccessFile file, int codeOff) throws IOException {
    if (codeOff == 0) {
        System.out.println("（抽象方法，无代码）");
        return;
    }
    
    file.seek(codeOff);
    
    int registersSize = Short.reverseBytes(file.readShort()) & 0xFFFF;
    int insSize = Short.reverseBytes(file.readShort()) & 0xFFFF;
    int outsSize = Short.reverseBytes(file.readShort()) & 0xFFFF;
    int triesSize = Short.reverseBytes(file.readShort()) & 0xFFFF;
    int debugInfoOff = Integer.reverseBytes(file.readInt());
    int insnsSize = Integer.reverseBytes(file.readInt());
    
    System.out.printf("寄存器数量: %d\n", registersSize);
    System.out.printf("参数寄存器数量: %d\n", insSize);
    System.out.printf("调用寄存器数量: %d\n", outsSize);
    System.out.printf("指令数量: %d\n", insnsSize);
    
    // 读取字节码
    System.out.println("\n字节码（16进制）:");
    for (int i = 0; i < insnsSize; i++) {
        int insn = Short.reverseBytes(file.readShort()) & 0xFFFF;
        System.out.printf("%04X ", insn);
        if ((i + 1) % 8 == 0) System.out.println();
    }
}

public static void modifyString(String dexPath, int stringId, String newValue) throws IOException {
    RandomAccessFile file = new RandomAccessFile(dexPath, "rw");
    
    // 1. 读取原字符串偏移
    file.seek(0x3C); // string_ids_off
    int stringIdsOff = Integer.reverseBytes(file.readInt());
    
    file.seek(stringIdsOff + stringId * 4);
    int oldStringDataOff = Integer.reverseBytes(file.readInt());
    
    // 2. 在文件末尾写入新字符串
    file.seek(file.length());
    long newStringDataOff = file.getFilePointer();
    
    // 写入 UTF-16 长度（ULEB128）
    writeULeb128(file, newValue.length());
    // 写入 MUTF-8 字符串
    file.write(newValue.getBytes("UTF-8"));
    file.writeByte(0); // null terminator
    
    // 3. 更新 StringId 指向新位置
    file.seek(stringIdsOff + stringId * 4);
    file.writeInt(Integer.reverseBytes((int) newStringDataOff));
    
    // 4. 更新校验和和签名（重要！）
    updateChecksum(file);
    updateSignature(file);
    
    file.close();
}

// 写入 ULEB128
public static void writeULeb128(RandomAccessFile file, int value) throws IOException {
    do {
        int b = value & 0x7F;
        value >>>= 7;
        if (value != 0) {
            b |= 0x80;
        }
        file.writeByte(b);
    } while (value != 0);
}

注意：直接修改 Dex 需要重新计算校验和和签名，否则会导致应用无法加载。

十二、Dex 文件加固与脱壳

12.1 常见加固方案

第一代：Dex 加密

  • 将 classes.dex 加密，运行时解密加载
  • 特征：APK 中没有 classes.dex 或只有壳 Dex

第二代：Dex 抽取

  • 保留类和方法定义，抽空方法体（DexCode）
  • 运行时动态恢复方法体

第三代：VMP/Dex2C

  • 将关键方法转换为 Native 代码或虚拟机指令
  • Dex 中只保留 JNI 调用

public static void dumpDex(ClassLoader classLoader) {
    try {
        Object pathList = XposedHelpers.getObjectField(classLoader, "pathList");

12.3 修复损坏的 Dex

# Python 脚本：修复 Dex 文件头
import struct
import hashlib

def fix_dex_header(dex_path):
    with open(dex_path, 'rb+') as f:
        data = f.read()
        
        # 修复文件大小
        file_size = len(data)
        f.seek(0x20)
        f.write(struct.pack('<I', file_size))
        
        # 重新计算 SHA-1 签名
        f.seek(0)
        f.read(32)  # 跳过 magic 和 checksum 和 signature
        signature = hashlib.sha1(data[32:]).digest()
        f.seek(12)
        f.write(signature)
        
        # 重新计算校验和
        f.seek(12)
        checksum = sum(data[12:]) & 0xFFFFFFFF
        f.seek(8)
        f.write(struct.pack('<I', checksum))
        
    print(f"已修复: {dex_path}")

十三、进阶阅读

13.1 MultiDex 机制

当方法数超过 65536 时，Android 会生成多个 Dex 文件：

app.apk
├── classes.dex      (主 Dex)
├── classes2.dex     (次 Dex)
├── classes3.dex
└── ...

主 Dex 选择规则：

  • Application 类及其依赖
  • 四大组件及其直接依赖
  • @Keep 注解的类

13.2 Dex 优化（Odex/Vdex）

ART 运行时优化：

原始 Dex → Vdex（验证后的 Dex） + Odex（AOT 编译的机器码）
  • Vdex：包含未压缩的 Dex 和验证信息
  • Odex：包含 AOT 编译的本地代码

获取优化后的文件：

adb shell
cd /data/app/com.example/oat/arm64/
ls -la
# base.odex, base.vdex

13.3 Compact Dex

Android 10+ 引入的紧凑格式：

Compact Dex = 共享数据段 + 压缩指令

优势：

  • 减少重复数据
  • 更小的文件体积
  • 更快的加载速度

总结

Dex 文件是 Android 应用的核心，理解其结构对逆向分析至关重要：

  1. DexHeader：文件元信息，定位各个区域
  2. StringIds：所有字符串常量，搜索特征字符串的入口
  3. TypeIds：类型描述符，理解类型系统
  4. ProtoIds：方法签名，识别方法原型
  5. FieldIds/MethodIds：字段和方法定义，定位目标成员
  6. ClassDef：完整的类定义，逆向分析的核心
  7. DexCode：Dalvik 字节码，实际执行逻辑

实战应用：

  • 使用 DexKit 快速定位混淆代码
  • 通过字符串特征查找加密方法
  • 手动解析 Dex 实现自定义工具
  • 理解加固原理，掌握脱壳技巧

推荐学习路径：

  1. 使用 dexdump 查看 Dex 结构
  2. 用 010 Editor 可视化学习各个字段
  3. 编写简单的 Dex 解析器
  4. 学习 DexKit 高效搜索
  5. 实践 Dex 修改和脱壳
